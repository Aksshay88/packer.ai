# Packer.ai - Intelligent Neovim Configuration Generator

An intelligent, AI-powered configuration generator for Neovim's Packer.nvim plugin manager. Built with emergent intelligence principles for context-aware, adaptive configuration generation.

## Features

### Core Intelligence System

- **Contextual Awareness**: Automatically infers "lovable" default configurations and essential dependencies
- **Adaptive Completion**: Intelligently suggests relevant `use` options based on best practices
- **Semantic Generation**: Produces syntactically correct, idiomatic Neovim/Packer Lua code
- **Extensibility**: Easily updatable plugin database with no system downtime

### Key Capabilities

1. **Smart Plugin Search**

   - Real-time fuzzy search across 15+ pre-loaded popular plugins
   - Automatic normalization of common shorthand names (e.g., 'telescope' → 'nvim-telescope/telescope.nvim')
   - Context-aware suggestions with descriptions

2. **Intelligent Configuration Generation**

   - Rule-based system for common plugins (instant generation)
   - AI-powered (GPT-5) enhancement for unknown/custom plugins
   - Automatic dependency detection and inclusion
   - Optional default configuration blocks with sensible defaults

3. **Configuration Management**

   - Save and organize multiple configurations
   - View, download, and delete saved configurations
   - Export to .lua files ready for immediate use

4. **Beautiful, Modern UI**
   - Clean, intuitive interface with real-time preview
   - Syntax-highlighted Lua code display
   - Responsive design with smooth animations
   - Ocean blue/cyan color scheme (no dark gradients)

## Architecture

### Emergence Principles Implementation

1. **Contextual Awareness**

   - Plugin database with metadata: name, repo, description, dependencies, default configs
   - Automatic dependency resolution (e.g., nvim-tree → nvim-web-devicons)
   - Pre-configured setup blocks for common plugins

2. **Adaptive Completion**

   - Supports all Packer options: `opt`, `branch`, `tag`, `requires`, `config`
   - Conditional config generation based on user preference
   - Smart handling of single vs. multiple dependencies

3. **Semantic Generation**

   - Proper Lua syntax with correct indentation (2-space for blocks, 4-space for content)
   - Idiomatic Neovim patterns (e.g., `require('plugin').setup({})`)
   - Complete, ready-to-use Packer configurations

4. **Extensibility**
   - MongoDB-based plugin database (easily updated via API)
   - Fallback to AI generation for unknown plugins
   - Hot-reloadable plugin metadata

## API Endpoints

### Plugin Management

- `GET /api/plugins` - List all available plugins
- `GET /api/plugins/search?q={term}` - Search plugins by name/description

### Configuration Generation

- `POST /api/plugin/generate` - Generate single plugin use block
- `POST /api/config/generate` - Generate complete Packer configuration

### Configuration Storage

- `POST /api/config/save` - Save a configuration
- `GET /api/config/list` - List all saved configurations
- `GET /api/config/{id}` - Get specific configuration
- `DELETE /api/config/{id}` - Delete a configuration
- `POST /api/config/export` - Export configuration to file

## Example Generated Configuration

```lua
-- Packer.nvim configuration
-- Generated by Packer.ai

return require('packer').startup(function(use)
  -- Packer can manage itself
  use 'wbthomason/packer.nvim'

  use {
    'nvim-telescope/telescope.nvim',
    requires = 'nvim-lua/plenary.nvim',
    config = function()
      require('telescope').setup({
        defaults = {
          prompt_prefix = '🔍 ',
          selection_caret = '➜ ',
          path_display = {'smart'},
        },
      })
    end,
  }

  use {
    'nvim-tree/nvim-tree.lua',
    requires = 'nvim-tree/nvim-web-devicons',
    config = function()
      require('nvim-tree').setup({
        view = {
          width = 30,
        },
        renderer = {
          group_empty = true,
        },
        filters = {
          dotfiles = false,
        },
      })
    end,
  }
end)
```

## Usage

1. **Search for plugins** using the search bar or select from popular plugins
2. **Add plugins** to your configuration by clicking on search results or popular plugin badges
3. **Enable configurations** (optional) to include default setup blocks
4. **Generate** your Packer configuration with the "Generate Configuration" button
5. **Save** your configuration for later use or **Download** as a .lua file
6. **View saved configurations** to manage your collection

## AI Enhancement

For plugins not in the database, the system uses GPT-5 to:

- Generate appropriate use blocks
- Suggest common dependencies
- Provide sensible default configurations
- Follow Neovim/Packer best practices
